The Elder Scrolls II: Daggerfall

ダガーフォール 日本語化MOD

GOG.com 版の「The Elder Scrolls II: Daggerfall」（DOS 版）を日本語で遊べるようにする、非公式のファンメイドMODです。 画面の知らせ、町の人々との会話、クエストの文、本（読み物）、人物作成の問答と種族・職業の説明、品物・呪文・技能の名前、町や人の名前、メニューやボタンの絵の文字まで、ゲームの中の文章を日本語にしています。 日本語の字は、DOSBox が画面を拡大して映すときに 14 ドットの細かい字で描くので、読みやすくなっています。 ゲームのフォルダにファイルを 1 つ置くだけで日本語になり、消せば英語に戻ります。

ゲーム本体の「The Elder Scrolls II: Daggerfall」は、GOG.com で無料で手に入ります。

どんなゲーム？

ダガーフォールは、1996年にベセスダ・ソフトワークスが発表した、エルダースクロールズ シリーズの第2作です。

皇帝ユリエル・セプティム7世の密命を受けた主人公は、イリアック湾の王国ダガーフォールへ向かいます。 都に現れるという先王ライサンダスの亡霊を鎮め、皇帝が王妃に送った一通の手紙の行方を探ること。 ところが船は嵐で沈み、主人公は岬の洞窟に閉じ込められたところから旅を始めます。

舞台はイリアック湾を囲むハイロックとハンマーフェルの国々で、数えきれないほどの町や村、ダンジョンが広がっています。 ギルドや騎士団に入って依頼をこなし、家や船を買い、王国どうしの陰謀に関わりながら、自由に生きていくことができます。

画面

入れ方

  1. ダウンロードした Daggerfall_JP.zip の中身を、ゲームのフォルダ（FALL.EXE があるフォルダ）にそのまま展開します。
  2. ゲームのフォルダの中の DOSBOX フォルダに winmm.dll が増えれば完了です。元からあるファイルを上書きすることはありません。
  3. いつもどおり GOG Galaxy やショートカットから起動します。

ゲームのファイルは書き換えません。

外し方

  • DOSBOX フォルダから winmm.dll を消します。

セーブデータは英語版と共通です。ただし、日本語版で始めたゲームでは品物の名前などがセーブの中に日本語で残るため、英語版に戻すとその部分は読めない文字になります。新しく始めたゲームで遊ぶことをおすすめします。

遊ぶときの注意

  • 町や人の名前は、画面ではカタカナで表示しますが、ゲームの中では英語のまま扱われます。旅の地図で場所を探すときは英語の名前（Daggerfall、Wayrest など）を入力します。
  • 日本語化を入れる前に始めたゲームでは、すでに会った人の名前などが英語のまま残ります。
  • 名前やセーブの説明は英字で入力します。
  • タイトルのロゴ、画面左下の縦書きの「OPTIONS」、大陸の地図の細かい地名など、一部の絵の文字は英語のままです。
  • オープニングなどの動画の声には字幕がありません。
  • GOG 版と中身が違う DOSBox やゲームファイルのときは、日本語化せず英語のまま動きます。

Daggerfall Unity 1.1.1 日本語化

ダガーフォールをファンが作り直した「Daggerfall Unity」用の日本語化も用意しています。訳は DOS 版と同じで、Daggerfall Unity 独自のメニューや設定画面も日本語にしています。字は BIZ UDPゴシックで、なめらかに表示します。

Daggerfall Unity は無料で、ゲーム本体とは別に入れます。遊ぶには、GOG.com 版などのダガーフォールのデータも要ります。

Daggerfall Unity 1.1.1 日本語化のダウンロード（GitHub）Daggerfall Unity の公式サイトDaggerfall Unity 1.1.1 本体のダウンロード（公式）

入れ方（Daggerfall Unity 1.1.1 日本語化）

  1. Daggerfall Unity 1.1.1 を公式サイトの手順どおりに入れ、英語のまま一度起動できる状態にします。
  2. 念のため、Daggerfall Unity のフォルダの中の DaggerfallUnity_Data\StreamingAssets\Text と Fonts を別の場所に写して残しておきます。
  3. ダウンロードした DaggerfallUnity_JP.zip の中身を、Daggerfall Unity のフォルダ（DaggerfallUnity.exe があるフォルダ）にそのまま展開し、上書きします。
  4. 起動したら、タイトルの前の設定画面の「SDF Font Rendering」に必ずチェックを入れます。

英語に戻すときは、残しておいた Text と Fonts を元の場所に戻し、StreamingAssets\Textures の中の Img と CifRci フォルダを消します。

  • Daggerfall Unity 版では、旅の地図で場所を探すときは日本語（カタカナ）で入力します。
  • ほかのMODが足す文章（クエストや本など）は英語のままです。
