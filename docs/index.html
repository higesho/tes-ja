日本語化プロジェクト

エルダースクロールズ シリーズ 日本語化プロジェクト

エルダースクロールズ（The Elder Scrolls）シリーズの初期の作品を日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。 GOG.com で販売されている DOS 版を対象にしています。 どのMODも、ゲームのファイルを書き換えずに日本語で遊べるようにし、外せば英語に戻ります。

作品一覧

  • 公開中 アリーナ The Elder Scrolls: Arena（1994年） 帝国魔闘士ジャガル・サーンに皇帝の座を奪われたタムリエル。地下牢から脱け出し、八つに砕かれた混沌の杖を集めて皇帝を救うシリーズ第1作。 紹介とダウンロード
  • 公開中 ダガーフォール The Elder Scrolls II: Daggerfall（1996年） 皇帝の密命を受けてイリアック湾の王国ダガーフォールへ渡り、亡き王の霊の謎を追うシリーズ第2作。 紹介とダウンロード

このプロジェクトについて

  • 非公式のファンメイドMODです。ゲーム本体は GOG.com などで入手してください。
  • MODはゲームのファイルを書き換えません。配布物には原作のプログラムやデータは入っていません。
  • 日本語の表示には、美咲フォント（8×8 ドット）と東雲フォント（14×14 ドットほか）を使っています。
