日本語化プロジェクト

The Elder Scrolls: Arena

アリーナ 日本語化MOD

GOG.com 版の「The Elder Scrolls: Arena」（DOS の CD-ROM 版）を日本語で遊べるようにする、非公式のファンメイドMODです。 王や依頼主・町の人々の会話、本筋の語り、キャラクター作成の問いと説明、店や宿のやりとり、ダンジョンの看板や謎かけ、品物・呪文・地名・人名・種族・職業の名前、メニューやメッセージまで、ゲームの中の文章を日本語にしています。 日本語の字は、DOSBox が画面を拡大して映すときに 14 ドットの細かい字で描くので、読みやすくなっています。 ゲームのフォルダにファイルを置くだけで日本語になり、外せば英語に戻ります。

ゲーム本体の「The Elder Scrolls: Arena」は、GOG.com で無料で手に入ります。

ダウンロード（GitHub）GOG.com のストア（無料）

どんなゲーム？

アリーナは、1994年にベセスダ・ソフトワークスが発表した、エルダースクロールズ シリーズの第1作です。

大陸タムリエルを治める皇帝ユリエル・セプティム七世は、帝国魔闘士ジャガル・サーンの裏切りによって異界へ囚われ、サーンが皇帝の姿で玉座に就きました。 帝国地下牢に捕らわれた主人公は、サーンに殺された弟子リア・シルメインの霊に導かれて脱出し、八つに砕かれて各地に隠された「混沌の杖」を集める旅に出ます。

画面は一人称の立体で、タムリエル全土の町や村、野外、無数のダンジョンを自由に歩き回れます。 職業や種族を選んで人物を作り、町で噂を聞き、王から依頼を受け、怪物と戦いながら杖のかけらの在りかを探します。

入れ方

  1. ダウンロードした Arena_JP.zip の中身を、ゲームのフォルダ（ACD.EXE があるフォルダ）にそのまま展開します。
  2. ゲームのフォルダの中の DOSBOX フォルダに、winmm.dll と ARENAJP フォルダが増えれば完了です。元からあるファイルを上書きすることはありません。
  3. いつもどおり GOG Galaxy やショートカットから起動します。

ゲームのファイルは書き換えません。

外し方

  • DOSBOX フォルダから winmm.dll と ARENAJP フォルダを消します。
  • 一時的に英語で遊びたいときは、DOSBOX\ARENAJP\arenajp.ini の Enable=1 を Enable=0 に書き換えます。

セーブデータは英語版と共通です。日本語版と英語版を行き来しても、続きから遊べます。

遊ぶときの注意

  • 都市・町・村の名前や町の人々の名前は、画面ではカタカナで表示しますが、ゲームの中では英語のまま扱われます。町の名前を打ち込んで探すときは英語で入力します。
  • ダンジョンの謎かけの答えは英語で入力します。
  • 名前やセーブの名前は英字で入力します。
  • 日本語の字は、窓や全画面に映すときに 14 ドットで描きます。8 ドットの字で遊びたいときは、DOSBOX\ARENAJP\arenajp.ini に Hires=0 の 1 行を足します。
  • メインメニュー、オープニングの物語、地図の州名、能力値・持ち物・呪文書の画面など、絵として描かれた文字も日本語に描き直しています（方角の目盛りなど、ごく小さな文字は英語のままです）。
